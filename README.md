# Челлендж Tinker

В субботу, 20 сентября 2025 года в РТУ МИРЭА, прошел практический челлендж для разработчиков, посвященный программированию робототехнических систем. Участники работали над созданием ROS2 Node на C++ для управления шагающим роботом Tinker. 

В рамках челленджа участники могли выбрать одно из нескольких направлений, чтобы сосредоточиться на наиболее интересной для них области разработки.

Перед разделением на команды и работой над выбранными треком участники узнали о деятельности кружка робототехники Сбер. 

![Вступительная лекция](/images/4.jpg)

### Трек 1: Сборка шагающего робота.

Участники превращали наборы распечатанных на 3D-принтере деталей и электронных компонентов в функционирующего шагающего робота, готового к программированию. Параллельно требовалось написать подробную инструкцию по сборке робота с картинками.

![Команда участников собирает робота](/images/track_1.jpg)

### Трек 2: Программирование STM32 контроллера spi2can управления моторами и написание для него ROS2 node на стороне компьютера.

От участников требовалось:

- Собрать стенд с одним мотором и spi2can контроллером который соединяется с одноплатным компьютером odroid или raspberry.
- Написать прошивку spi2can контроллера, для stm32. Она должна общаться с моторами передавая данные через spi на большой компьютер.
- Написать ROS2 драйвер ноду которая общается с контроллером через spi.
- Покрутить моторами через топики ROS2.

![Собранный стенд трека 2](/images/track_2.jpg)
